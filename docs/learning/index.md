# Bethink Learning

This section is a guided path for becoming a Bethink power user. The regular
docs explain features. These lessons teach habits: how to build a vault, keep it
useful, use AI safely, and turn repeated work into repeatable systems.

You do not need to be technical to start. Work through the path in order the
first time, then return to specific lessons when you need a refresher.

## How to use this section

- **Read one lesson at a time.** Each one is meant to be practiced inside your
  own vault.
- **Do the exercises.** Bethink rewards use. A clean system comes from small
  repeated actions, not from reading everything first.
- **Keep the reference docs nearby.** When a lesson mentions a feature, the
  linked guide gives the exact details.

## Power-user map

Bethink power users know how these pieces fit:

| Concept | Plain meaning | Power-user habit |
|---|---|---|
| **Vault** | A folder of Markdown files. | Keep one vault per major life/work area unless the boundaries are fuzzy. |
| **Page** | One note or document. | Give pages clear titles and link them early. |
| **Folder** | A real folder on disk. | Use folders for ownership and lifecycle, not every possible topic. |
| **Tag** | A reusable label inside page text. | Use tags for status, workflows, and cross-cutting themes. |
| **Link** | A `[[Page]]` connection. | Link ideas before you fully understand the structure. |
| **Search** | Fast retrieval across the vault. | Learn operators instead of over-organizing. |
| **AI chat** | A model grounded in a page or vault search. | Ask it to cite notes and say when evidence is missing. |
| **Agent** | A named role with instructions and tools. | Create agents for repeated jobs, not every one-off question. |
| **Channel** | A workspace with one or more agents. | Use channels for projects and longer-running efforts. |
| **Project** | A local folder linked to Bethink. | Keep read/write/run permissions explicit. |
| **Memory** | Durable facts from prior work. | Pin durable facts; delete noisy memories. |
| **Harness** | Scenarios and run results for agent behavior. | Test repeatable agent workflows before trusting them. |

## Graduation checklist

You are operating Bethink like a power user when you can:

- Open or create a vault and explain where the files live.
- Create pages quickly with the keyboard and slash menu.
- Use links, backlinks, tags, and search together instead of relying on one
  giant folder tree.
- Run a weekly review that cleans stale notes and promotes useful ideas.
- Ask AI questions grounded in your vault and verify answers against sources.
- Create an agent with a clear role, limited tools, and a readable profile.
- Use a channel to coordinate agents around a project or recurring workflow.
- Link a project folder, understand permissions, and review proposed changes
  before approving them.
- Inspect run history, memory, and loop stops when an agent behaves strangely.
- Use plugins or MCP only when they solve a real workflow problem.
