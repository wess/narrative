# Course 4 — Review Routines

Goal: keep your vault useful after the first week. A vault without review turns
into a pile. A vault with light review becomes a working memory.

## The review principle

Review is not cleaning for its own sake. Review answers four questions:

1. What is still active?
2. What is waiting on someone or something?
3. What did I decide?
4. What should be easy to find later?

## Daily shutdown

Use this at the end of a work session. It should take five minutes.

1. Open today's daily note or your `Inbox`.
2. Write three bullets:
   - What moved forward?
   - What is blocked?
   - What needs attention next?
3. Link each bullet to the relevant page when possible.
4. Move any important action into the right project page.
5. Pin tomorrow's active page if you know it.

### Daily shutdown template

```md
## Shutdown

Moved forward:

- 

Blocked:

- 

Next:

- [ ]
```

## Weekly review

Use this once a week. It should take 20 to 45 minutes.

1. Search for `#review/weekly`.
2. Search for open to-dos.
3. Review active project pages.
4. Promote useful facts from daily notes into durable pages.
5. Archive stale pages that no longer need attention.
6. Pin or unpin pages based on the next week.
7. Ask AI to summarize open decisions, then verify against linked pages.

### Weekly review page shape

```md
# Weekly Review: <date>

## Wins

## Open loops

## Decisions made

## Pages updated

## Next week

- [ ]
```

## Project review

Projects need a tighter review:

| Section | Question |
|---|---|
| Goal | Is the desired outcome still clear? |
| Status | Is it active, waiting, done, or parked? |
| Decisions | What did we decide and why? |
| Risks | What can break or surprise us? |
| Next actions | What is the next visible move? |
| Linked pages | Are the important notes connected? |

If a project is still active but has no clear next action, it is not really
being managed.

## AI-assisted review

AI can help review, but it should not replace your judgment.

Good prompts:

- "Summarize open loops from this project page. Use only the page content."
- "Find contradictions across these linked notes."
- "List decisions in this page and separate them from open questions."
- "What should I promote from this daily note into durable project notes?"

Bad prompts:

- "What should I do with my life?"
- "Clean this vault for me."
- "Tell me everything important."

Ask narrower questions. Verify sources.

## Memory review

Agents can accumulate memory. Review memory when an agent starts acting on old
or wrong assumptions.

During memory review:

- Pin facts that should persist.
- Delete noisy or incorrect memories.
- Prefer specific facts over broad summaries.
- Keep channel memory focused on that channel's purpose.

## Exercises

1. Create a `Weekly Review` page using the template above.
2. Search for open to-dos and close or rewrite five of them.
3. Add `#review/weekly` to three pages that need recurring attention.
4. Ask the AI assistant to summarize one project page, then verify the answer.
5. Open the memory manager and delete one memory that would not help future work.

## Power-user checkpoint

Your review system is working when:

- You know what is active.
- Old notes do not hide current work.
- Decisions are easy to find.
- Daily notes feed durable notes instead of becoming the only record.
- AI helps you inspect the vault but does not become the vault.
