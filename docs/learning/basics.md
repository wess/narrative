# Course 1 — Bethink Basics

Goal: understand what Bethink is, where your knowledge lives, and how to move
around without feeling lost.

## Lesson 1: The vault model

Bethink is built around one simple rule:

> A vault is a folder of Markdown files. The folder is the source of truth.

That means:

- Pages are real `.md` files.
- Folders are real folders.
- Attachments are real files.
- The search index is rebuilt from your files.
- You can back up, sync, version, or inspect your vault with normal tools.

### Practice

1. Open Bethink.
2. Create a page named `Learning Bethink`.
3. Add a sentence and save.
4. Find that page in the vault folder on disk.
5. Open it in a text editor and confirm it is Markdown.

## Lesson 2: The main workspace

Bethink has five areas you will use constantly:

| Area | What it is for |
|---|---|
| Sidebar | Pages, folders, projects, agents, channels, and quick actions. |
| Editor | Writing and editing pages. |
| Topbar | Navigation, view controls, and high-level actions. |
| Right panel | Outline, outgoing links, and backlinks for the current page. |
| Chat drawer | AI assistant, active agent, or active channel conversation. |

The fastest way to learn the app is to use the command palette. Press `⌘K`,
type what you want, and run it.

### Practice

1. Press `⌘K`.
2. Search for `new page`.
3. Search for `graph`.
4. Search for `settings`.
5. Search for `summarise` after opening a page.

## Lesson 3: Pages, folders, and titles

Use pages for ideas, decisions, notes, plans, references, and drafts. Use
folders for broad ownership or lifecycle. Avoid creating a folder for every
topic before you know how the vault will grow.

Good page titles are concrete:

- `Q3 Roadmap Decisions`
- `Customer Interview Notes`
- `Bethink Agent Ideas`
- `Project Launch Checklist`

Weak page titles are vague:

- `Stuff`
- `Notes`
- `Ideas 2`
- `Meeting`

### Practice

Create these pages:

1. `Inbox`
2. `Projects`
3. `People`
4. `Decisions`
5. `Questions`

They do not need much content yet. They give your vault a simple starting map.

## Lesson 4: Daily navigation habits

Power users do not click through the tree for everything. They mix navigation
methods:

- Use `⌘K` for commands.
- Use search for pages you remember vaguely.
- Use backlinks for context.
- Use the graph when you need a visual map.
- Use daily notes for work that belongs to a date.
- Pin pages that are active right now.

### Practice

For one normal work session:

1. Open pages through search instead of the tree.
2. Pin one page you expect to use again today.
3. Open the graph once and inspect nearby pages.
4. End by writing one sentence in `Inbox` about what you learned.

## Common mistakes

- **Overbuilding structure too early.** Start with fewer folders and more links.
- **Using tags for everything.** Tags are best for state and cross-cutting
  categories.
- **Treating AI as the source of truth.** Your vault is the source of truth.
- **Ignoring file ownership.** If a vault matters, back it up like any other
  important folder.

## Power-user checkpoint

You understand Bethink basics when you can:

- Explain what a vault is.
- Find a page on disk.
- Create and open pages without hunting through menus.
- Use the command palette for common actions.
- Choose when to use a folder, page, link, or search.
