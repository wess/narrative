# Keyboard shortcuts

Narrative is built to be driven from the keyboard. `⌘` is the modifier on
macOS; use `Ctrl` on Linux and Windows.

## File

| Shortcut | Action |
|---|---|
| `⌘N` | New page |
| `⌘D` | New / open today's daily note |
| `⌘O` | Open vault… |
| `⌘E` | Export current page… |
| `⌘,` | Open settings |
| `⌘Q` | Quit |

## Edit

| Shortcut | Action |
|---|---|
| `⌘Z` | Undo |
| `⌘⇧Z` | Redo |
| `⌘X` | Cut |
| `⌘C` | Copy |
| `⌘V` | Paste |
| `⌘A` | Select all |

## View & navigation

| Shortcut | Action |
|---|---|
| `⌘K` | Command palette — jump to a page or run any command |
| `⌘⇧F` | Search the vault |
| `⌘⇧G` | Graph view |
| `⌘⇧T` | Tags view |
| `⌘J` | Toggle the AI assistant |
| `⌘F` | Find in the current note |
| `⌘W` | Close the current tab |
| `⌘⇧L` | Toggle light / dark theme |

## In the editor

| Type this | Result |
|---|---|
| `/` | Open the slash menu |
| `# `, `## `, `### ` | Headings 1–3 |
| `- ` / `* ` | Bulleted list |
| `1. ` | Numbered list |
| `[] ` | To-do item |
| `> ` | Quote |
| `> [!warning] ` | Callout |
| ` ``` ` | Code block |
| `$$` | Math block |
| `---` | Divider |
| `[[` | Wiki-link autocomplete |
| `**bold**`, `*italic*`, `~~strike~~`, `` `code` `` | Inline formatting |

## The command palette

Not every action has a dedicated shortcut — but **`⌘K` finds all of them**. The
palette searches every command *and* every page, so it doubles as a quick page
switcher. Highlights you'll find there include "Open a random page",
"Summarise current page with AI", and every command contributed by an enabled
[plugin](plugins.md).

If you forget a shortcut, press `⌘K` and type what you want to do.
